## 🌟 行程亮點搶先看
* 🏛️ **喬治市世界文化遺產：** 乘著復古三輪車穿梭百年古城，尋覓街頭壁畫與浪漫鐵線藝術。
* 🌉 **蘭卡威天空之橋：** 挑戰世界最大彎曲吊橋，漫步雲端、俯瞰壯闊的安達曼海絕景。
* ⛵ **浪漫夕陽遊艇 PARTY：** 迎著海風暢遊海上！享受海水拖網按摩浴、驚險刺激的跳海游泳，還有無限暢飲的微醺派對與落日晚宴。
* 🍽️ **在地老饕必嚐：** 手抓海鮮、豪華虎蝦餐、道地南洋肉骨茶，以及米其林必比登推薦的夢幻娘惹糕！

## 📅 每日精華行程

### 📍 Day 1：12/03（四） 桃園 ✈️ 檳城 ➔ 檳城地標巡禮
* **行程內容：** 懷著興奮的心情搭機前往檳城 ➔ 抵達後展開古城巡禮：外觀康華麗斯古堡、遠眺蔚藍的麻六甲海峽 ➔ 漫步檳城大鐘樓 ➔ 搭乘復古三輪車穿梭於愛情巷與百年英校間，感受濃厚的南洋文藝氣息 ➔ 品嚐清涼消暑的火龍果霜淇淋。
* **餐食：** 早餐（敬請自理）｜午餐（機上精緻餐食）｜晚餐（道地吮指手抓海鮮 RM50）
* **住宿：** Hompton by the Beach Penang / CITITEL PENANG 或同級

### 📍 Day 2：12/04（五） 檳城 ➔ 蘭卡威 ➔ 水上人家與洋人街
* **行程內容：** 探訪充滿人文風情的「姓氏橋」水上人家 ➔ 走進趣味十足的食物狂想館拍照打卡 ➔ 乘船出海前往美麗的海島度假天堂——蘭卡威 ➔ 遠眺地標老鷹廣場，漫步熱鬧的瓜鎮與洋人街，感受悠閒的海島夜生活。
* **餐食：** 早餐（飯店內用）｜午餐（自理：新世界小吃中心品嚐在地小吃）｜晚餐（澎湃海鮮餐＋每人一隻大虎蝦＋清涼啤酒或汽水 RM80）
* **住宿：** Resorts World Langkawi（Sea View）／Dayang Bay Resort Langkawi 或同級（浪漫海景房）

### 📍 Day 3：12/05（六） 蘭卡威 ➔ 天空步道 ➔ 浪漫夕陽遊艇派對
* **行程內容：** 探訪東方村，搭乘高空纜車直衝山巔 ➔ 挑戰驚險刺激的世界最大彎曲吊橋「天空步道」，腳踩雲霧、俯瞰 360 度無敵海景！➔ **【重頭戲登場】** 登上專屬豪華遊艇，展開嗨翻天的安達曼海夕陽派對！跟著音樂擺動、體驗獨特的「海水拖網按摩浴」、大膽躍入蔚藍大海暢游、盡情高歌海上卡拉OK，在金黃色的海平線落日陪伴下，享用豐盛的遊艇晚宴與無限暢飲！
* **餐食：** 早餐（飯店內用）｜午餐（開胃泰式餐 RM50）｜晚餐（遊艇澎湃自助餐＋啤酒、汽水、飲料無限暢飲）
* **住宿：** Resorts World Langkawi（Sea View）／Dayang Bay Resort Langkawi 或同級（浪漫海景房）

### 📍 Day 4：12/06（日） 蘭卡威 ➔ 檳城 ➔ 和諧街與米其林美食
* **行程內容：** 帶著依依不舍的心情搭船返回檳城 ➔ 參觀莊嚴宏偉的臥佛寺與緬佛寺 ➔ 漫步多元宗教融合的「和諧街」（觀音亭、印裔清真寺、聖喬治教堂）➔ 採買南洋特色土產 ➔ **【饕客必訪】** 品嚐米其林必比登推薦的「莫定標娘惹糕」，入口即化的香甜滋味讓人難忘！
