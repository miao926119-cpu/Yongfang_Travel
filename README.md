•	高空纜車如遇維修、強風或天候因素停駛，原行程說明將安排海底世界替代；天空步道若受天候或維修影響，可能改為遠觀。
•	購物安排：土產、咖啡（巧克力）。
•	每位旅客每日提供1瓶礦泉水；全程佔床旅客提供上網卡，每日流量1G。
•	領隊、導遊及司機小費：每人每天 NT$300。
